# Ideation space for Adobe Workfront Planning release activity

<span class="preview">The information on this page refers to functionality not yet generally available. It is available only as part of the **Ideation space Beta** program. </span>   

<span class="preview">For more information, see [Get started with Ideation space for Adobe Workfront Planning](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md).</span>

This article describes the features that are releasing for Ideation space for Workfront Planning during the **Ideation space Beta** period. The Open Beta for Ideation space is scheduled to run between November 12, 2026 and February 1, 2027. 

For Adobe Workfront Planning releases, see [Adobe Workfront Planning release activity: article index](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md).

## New Home area for Ideation space in Adobe Workfront Planning

>[!NOTE]
>
>Available to Preview and Production environments for Ideation space beta customers: November 25, 2026

When you access Ideation space from the Workfront waffle menu, you now open the Ideation space Home area. From here, you can reopen an existing canvas or create one, so you no longer need to start with a blank canvas just to get to an existing one. The Home area displays your recent canvases as tiles, lists all other canvases in the lower part of the screen, and includes a search box. When you're working inside a canvas, use the new Home button to return to Ideation space Home area. 

For information, see [Create briefs in the Ideation space](/help/quicksilver/planning/ideation/create-briefs-in-ideation-space.md).
