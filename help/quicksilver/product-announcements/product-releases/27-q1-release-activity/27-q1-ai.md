# First Quarter 2027 AI enhancements

This page describes AI enhancements made with the First Quarter 2027 release to the Preview environment. These enhancements will be made available in the Production environment as noted.

For a list of all changes available at this point in the First Quarter 2027 release cycle, see [First Quarter 2027 release overview](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Work Agents: Adobe Native support

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

To make it easier to bring AI-powered work into your workflows, we've added Adobe Native as a supported origin for Work Agents.

You can now create a Work Agent that uses Adobe CX Coworker without configuring a separate external platform or entering external credentials. This gives teams a faster way to get started while keeping the same Workfront task-assignment and execution model.

The setup experience also now reflects origin-based differences between Adobe Native and external-platform agents, including the prerequisites and configuration flow for each option. 

Native agents can be added to a task using @mention in the comments for the task.

For more information, see [Configure AI Collaborators](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md) and [Use Work Agents](/help/quicksilver/manage-work/tasks/assign-tasks/use-task-collaborators.md).

## Some icons removed from Adobe CX Enterprise Coworker in Workfront

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

To simplify Adobe CX Enterprise Coworker in Workfront, we've removed the following icons:

* Settings
* Artifacts

These actions are still available in the Adobe Coworker interface.

For more information on Adobe CX Enterprise Coworker in Workfront, see [Overview of CX Enterprise Coworker in Workfront](/help/quicksilver/workfront-basics/coworker-in-workfront/coworker-overview.md).
