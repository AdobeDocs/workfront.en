# First Quarter 2027 AI enhancements

This page describes AI enhancements made with the First Quarter 2027 release to the Preview environment. These enhancements will be made available in the Production environment as noted.

For a list of all changes available at this point in the First Quarter 2027 release cycle, see [First Quarter 2027 release overview](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Workfront MCP server toolsets

>[!NOTE]
>
>Preview: October 21, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

To make it easier to control which Workfront capabilities an AI client can access, we've added toolsets to the Workfront MCP server. You can now limit the MCP catalog to the capabilities your client needs instead of exposing the full authorized tool list. Available toolsets include `core`, `comment-stream`, `planning`, and `approvals`.

Tool availability now also reflects product entitlements more clearly. Customers licensed only for Workfront Planning see Planning tools, customers licensed only for Workfront Workflow see Workflow tools, and customers licensed for both see both sets. 

For more information, see [Configure the Adobe Workfront MCP server](/help/quicksilver/workfront-basics/workfront-mcp-server/configure-workfront-mcp-server.md) and [Use the Adobe Workfront MCP server](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md).
