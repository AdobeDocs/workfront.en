# First Quarter 2027 Project enhancements

This page describes Project enhancements made with the First Quarter 2027 release to the Preview environment. These enhancements will be made available in the Production environment as noted.

For a list of all changes available at this point in the First Quarter 2027 release cycle, see [First Quarter 2027 release overview](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Pin important threads to the top of updates

>[!NOTE]
>
>Preview: October 15, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

To make key decisions easier to find, you can now pin top-level comment threads on projects, tasks, issues, documents, programs, and portfolios. Pinned threads appear in a "Pinned threads" section above the update stream which is always visible. Each object supports up to 10 pinned threads. Anyone who can view the object can see the pinned threads, pin and unpin them. 

For information, see Update work (help/quicksilver/workfront-basics/updating-work-items-and-viewing-updates/update-work.md).
