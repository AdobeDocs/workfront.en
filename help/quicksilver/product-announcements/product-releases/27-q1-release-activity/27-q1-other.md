# Other enhancements during the First Quarter 2027 release timeframe

This page describes enhancements made with the First Quarter 2027 release to the Preview environment. These enhancements will be made available in the Production environment as noted.

For a list of all changes available at this point in the First Quarter 2027 release cycle, see [First Quarter 2027 release overview](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## See the total record count in enhanced lists

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

The enhanced view now shows the total number of items, and the count updates automatically as you apply filters, search, or change the view. The items count always reflects your full filtered results based on your permissions.

For information, see [Use enhanced lists](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md).

## Better visibility of quick search findings in enhanced lists

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

When you use quick search in an enhanced list to find an item, the list eliminates all records that don't match the search and displays only the items that match.

Prior to this enhancement, all items were displayed with the ones that match the search results highlighted.

For information, see [Use enhanced lists](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md).

## Add sections to organize enhanced views

<!-- NOTE FROM CSV: Check whether the areas affected listed below are complete or if there are others. Confirm whether this belongs in the general Workfront release notes. -->

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

You can now create sections in the View dropdown menu of an enhanced list to organize related views as your list grows. You can name each section when you create it, then move views from My Views and Shared with Me into your custom sections. System views stay fixed in the System section.

This enhancement is available in the following areas: Requests, Home, Priorities in the Main Menu.

For information, see [Use enhanced lists](https://experienceleague.adobe.com/en/docs/workfront/using/basics/navigate/lists-in-adobe-workfront/enhanced-lists).

## Updates to enhanced lists

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

The following changes have been made to enhanced lists:

* You can now expand or collapse all groupings in an enhanced list using the arrow icon at the top of the first column. Previously, you could only expand or collapse all groups within the grouping settings.
* When creating a new view, you no longer have to select a view type if only one type is available.

For more information, see [Use enhanced lists](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md).

## Multiple screens updated to enhanced lists

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

The following Workfront lists now use the enhanced list format:

* Setup > Interface > Layout Templates
* Setup > Email > Notifications > Event Notifications, and Group Detail page > Event Notifications

Updates include the following for some or all of the lists:

* A new look and feel of the list, with updates to colors, formatting, and fonts.
* The option to create a new object in the list was moved to the top right and displays as a blue button.
* The toolbar was removed. Now, when you select one or more objects in the table, the action bar appears at the bottom of the list in blue.
* Some columns might have been repositioned or removed, or new columns were added.
* Some confirmations and warnings have been removed or changed.
* Saving in some lists is now automatic, and the Save button might have been removed.
* Some enhanced lists allow columns to be renamed or sorted.
* Some enhanced lists include the Column manager, which allows you to add and arrange columns. You can select columns by native or custom fields in Workfront.
* Icons within table cells have been replaced by More menus with multiple options.

>[!NOTE]
>
>Not all updates are available on all lists.

For more information, see [Use enhanced lists](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md).

## Show or hide hours in the calendar report Week view

>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

You can now show or hide the hours of the day in the Week view of a calendar report. Hide the hours for a simpler, more streamlined view of your week, or show them when you want a time-of-day scale. Use the toggle in the upper-right corner of the calendar to switch between the two.

For more information, see [View calendar reports and event details](/help/quicksilver/reports-and-dashboards/reports/calendars/view-calendar-reports-and-event-details.md).
