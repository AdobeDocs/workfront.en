## Updates to AI Collaborators

>[!NOTE]
>
>Preview: October 1, 2026
>Production fast release: October 14, 2026
>Production for everyone: October 15, 2026

To make AI Collaborators more flexible and powerful, we've made the following updates:

* You can now work with agents (Task Collaborators) using agents created in OpenAI Agents or IBM watsonx Orchestrate
* You can now work with agents on issues, in addition to tasks
* Work agents can now get context from documents attached to the task or issue
* Updates provided by AI Collaborators now appear in the Updates area in real time

For more information on AI Collaborators, see [Configure AI Collaborators](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md).

## Workfront MCP server tools now reflect product entitlements

>[!NOTE]
>
>Preview: October 1, 2026
>Production: October 15, 2026

To make the Workfront MCP server reflect each customer's licensed products more accurately, tool availability is now filtered by product entitlement.

* Customers licensed only for Workfront Planning see Planning tools, but not Workflow tools.
* Customers licensed only for Workfront Workflow see Workflow tools, but not Planning tools.
* Customers licensed for both Workfront Workflow and Workfront Planning see both sets of tools.
* Insights and context tools remain available to all customers.

If a customer is not entitled to a product area, the related tools do not appear in the tool list for that connection. Direct calls to unavailable tools are blocked.

For more information, see [Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## CX Enterprise Coworker now available in Workfront

>[!NOTE]
>
>Preview: Phased rollout beginning on September 3, 2026
>Production fast release: Phased rollout beginning on September 17, 2026
>Production for everyone: Phased rollout beginning on October 15, 2026

CX Enterprise Coworker is now available inside Workfront. Now, you can access CX Enterprise Coworker in a panel that is available throughout Workfront.

CX Enterprise Coworker Chat is a conversational interface for getting work done. Describe a goal in plain language, and Coworker plans the work, executes it across Workfront and your connected Adobe systems, validates the results, and brings the finished work back to you for approval. 

Coworker respects your organization's existing access controls, with read-only access by default, and system admins control when users get write access.

Coworker is replacing the current AI Assistant as a more powerful way to get work done. Coworker is part of the Adobe ecosystem, and is not limited to Workfront.

>[!IMPORTANT]
>
>CX Enterprise Coworker is not currently available to organizations in health care, finance, or some other industries with sensitive data. AI Assistant is still available to these organizations.

For more information, see [CX Enterprise Coworker overview](/help/quicksilver/workfront-basics/coworker-in-workfront/coworker-overview.md).

## New Share Feedback tool available in the Workfront MCP Connector

>[!NOTE]
>
>Preview: September 3, 2026
>Production fast release: September 17, 2026
>Production for everyone: October 15, 2026

To help us improve the Workfront MCP server, we've added a new tool to the Workfront MCP Connector:

For more information, see [Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## New Search Users tool available in the Workfront MCP Connector

>[!NOTE]
>
>Production: August 13, 2026

To help you find people in your Workfront instance faster, we've added a new tool to the Workfront MCP Connector:

* Search Users

Type a full or partial name into the Search Users tool to get back the top matching users. You can also choose to include AI Collaborator "bots" alongside regular users in the results.

As part of this change, the following tools were deprecated:

* Find document
* Find projects
* Find team by name
* Find user by name
* Get current user
* Get documents by scope

If you have workflows that use these tools, update them to use the Find ID by name, Find Workfront data, or Search Users tools instead.

For more information, see [Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## Assign AI Task Collaborators to tasks in Workfront

>[!NOTE]
>
>Preview: July 31, 2026
>Production fast release: August 13, 2026
>Production for everyone: August 13, 2026

To allow you to use your AI Agents to perform work in Workfront, we've created Task Collaborators. Task Collaborators are AI Collaborators that can be assigned directly to Workfront tasks, in addition to the existing Reviewer-type AI Collaborator used for document and asset reviews. Task Collaborators connect to agents you've configured in Copilot Studio, Claude, or Writer, and you assign them to tasks just as you would assign a user.

For more information, see [Configure AI Collaborators](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md).
