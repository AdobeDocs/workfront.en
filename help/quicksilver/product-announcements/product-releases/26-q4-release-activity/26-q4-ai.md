# Fourth Quarter 2026 AI enhancements

This page describes AI enhancements made with the Fourth Quarter 2026 release to the Preview environment. These enhancements will be made available in the Production environment as noted.

For a list of all changes available at this point in the Fourth Quarter 2026 release cycle, see [Fourth Quarter 2026 release overview](/help/quicksilver/product-announcements/product-releases/26-q4-release-activity/26-q4-release-overview.md).

## Assign AI Task Collaborators to tasks in Workfront

>[!NOTE]
>
>Preview: July 31, 2026
>Production fast release: August 13, 2026
>Production for everyone: October 15, 2026

To allow you to use your AI Agents to perform work in Workfront, we've created Task Collaborators. Task Collaborators are AI Collaborators that can be assigned directly to Workfront tasks, in addition to the existing Reviewer-type AI Collaborator used for document and asset reviews. Task Collaborators connect to agents you've configured in Copilot Studio, Claude, or Writer, and you assign them to tasks just as you would assign a user.

For more information, see [Configure AI Collaborators](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md).

## New Approvals tools available in the Workfront MCP Connector

>[!NOTE]
>
>Preview: July 30, 2026
>Production fast release: August 13, 2026
>Production for everyone: October 15, 2026

To expand the capabilities of the Workfront MCP Connector, we've added the following new tools:

* Add path to approval
* Remove path from approval
* Add stage to path
* Remove stage from path
* Reorder stages in path

Also, the following tools were extended to accommodate parallel approval paths:

* Get approval workflow info
* Create or update approval workflow
* Create approval from template

For more information, see [Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## Board tools available in the Workfront MCP Connector

>[!NOTE]
>
>Preview: July 30, 2026
>Production fast release: August 13, 2026
>Production for everyone: October 15, 2026

To expand the capabilities of the Workfront MCP Connector, we've added the following tools for working with Boards:

* Get board
* Get card
* Create board
* Create card
* Update card
* Connect card
* Create board tag
* Create, update, or delete checklist items
* Create, update, or delete board columns

For more information, see [Adobe Workfront MCP server tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).
