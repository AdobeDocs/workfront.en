# Use the Project Coordinator collaborator

The Project Coordinator is an out-of-the-box AI Collaborator that monitors your project for overdue tasks, follows up directly with task owners, and keeps the project owner informed — automatically, without configuring an external agent.

Unlike Task Collaborators, which connect to an agent you configure in Copilot Studio, Claude, or Writer, the Project Coordinator is a ready-to-use collaborator provided by Workfront.

## Project Coordinator overview

The Project Coordinator works at the project level, rather than being assigned to individual tasks. It:

* Reviews tasks on the project to identify which are on track and which are falling behind.
* Follows up directly with the owners of overdue tasks.
* Keeps the project owner copied on that follow-up communication.

This happens automatically in the background, so project status stays current without manual follow-up.
