# Adobe Creative Cloud Projects overview

You can access your Workfront projects directly from Adobe Photoshop, Illustrator, and InDesign, using the **Projects** panel on the left side of the app window.

![Workfront projects listed in the Projects panel](assets/cc-projects.png)

>[!NOTE]
>
>Screenshot asset `cc-projects.png` still needs to be supplied before this article can publish.

Projects that use Adobe cloud storage appear in the Projects panel. From there, you can open, edit, and save documents in a Workfront project without leaving the Creative Cloud app.

## What you can do from the Projects panel

* Open Workfront project folders and documents directly in Photoshop, Illustrator, or InDesign.
* Edit a document and save your changes back to the Workfront project.
* Request a document approval on a file, the same as you would from Workfront or Adobe Cloud Drive.

For more information, see [Use Workfront documents in Creative Cloud apps](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md).

## Related integrations

If you need to edit a file type that Photoshop, Illustrator, or InDesign doesn't open — for example, a Word document — use Adobe Cloud Drive instead. For more information, see [Adobe Cloud Drive overview](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md).
